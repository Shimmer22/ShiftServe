## 命令

```sh
cd /data/local/tmp/llama.cpp
LD_LIBRARY_PATH=/data/local/tmp/llama.cpp/lib \
ADSP_LIBRARY_PATH=/data/local/tmp/llama.cpp/lib \
GGML_HEXAGON_EXPERIMENTAL=1 \
./bin/llama-mtmd-cli --no-mmap \
  -m /data/local/tmp/models/Qwen2.5-VL-3B-Instruct-Q4_0.gguf \
  --mmproj /data/local/tmp/models/mmproj-model-f16.gguf \
  --image /data/local/tmp/shot0.png \
  --device HTP0 -ngl 99 -n 32 \
  -p "Describe this screenshot briefly."
```

## Hexagon / 后端

- 加载驱动 `libcdsprpc.so`；Arch **v79**；`HTP0` session 建立（`libggml-htp-v79.so`）
- LLM：`offloaded 37/37 layers to GPU`（HTP0）；HTP0-REPACK model ~1488 MiB；KV on HTP0 144 MiB（ctx 自动 fit 到 4096）
- CLIP/ViT：`clip_ctx: CLIP using OpenCL backend`（Adreno 830）；**未**走 HTP
- `--fit` 曾告警 HTP0 未上报 free memory / 无法满足 1024 MiB free target，但因用户已设 `-ngl 99` 继续加载成功
