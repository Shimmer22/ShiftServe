# 手机单闭环测试（2026-11-05）

新主平台 SM8650 上完成一轮真实 GUI 闭环，功能验收通过。
结果目录：`results/20261105-164339-184707-single-gui-loop/`（仅本地）。

## 任务和实际结果

在手机浏览器打开专用本地测试页，任务码随机生成为 `PINE-95`：

1. 采集实时截图，模型读出任务码，生成
   `{"action":"tap","x":508,"y":358,"memo":"PINE-95"}`。
2. 独立执行器读取 UI accessibility 中唯一的 `COMPLETE TASK` 按钮边界，
   校验模型坐标和任务码，将模型输入图坐标映射到手机 `(1210, 852)`，实际执行一次点击。
   未把按钮中心或任务码代填给模型。
3. 浏览器收到真实用户输入事件，向本次服务报告完成，并将页面改为 DONE、移除任务码。
4. 收到页面更新确认后才采集第二张实时截图。相同模型进程复用首轮历史，返回
   `{"action":"done","memo":"PINE-95"}`。

两轮均严格 JSON、提交 EOG、模板前缀与状态恢复检查通过；第二轮复用首轮
743 个已评估 token 和相同字节数的状态。两张截图各编码一次，共2次。
原始截图、等比缩图、实际动作、UI 边界、HTTP 页面事件、host/native 协议、
进程资源采样和完整设备文件均保留。模型进程和本次 adb reverse 已清理。

独立 `audit.json` 的10项核验通过，包括设备结果与协议一致、单进程、历史复用、
两张不同实时截图，以及“首轮响应→实际点击→环境更新→第二张截图→最终确认”的事件顺序。

## 执行配置与边界

配置为 `configs/single-loop.json`：双 CPU/HTP context 驻留，实际两轮均
CPU prefill/CPU decode，OpenCL 视觉、FA off，ctx6144、batch128，关闭
KV 整理、预搬移、权重 repack、成对 prefill 和投机准备。此次未验证 HTP
执行或调度收益；初始化、视觉、prefill、decode、恢复与 snapshot 分别记录。

手机当时为横屏2400×1080，保持原设置。原始截图完整保留，模型输入等比缩至
1008×454，坐标按同一缩放关系还原。GBNF 只约束允许的动作 JSON 结构，不写入
正确任务码、坐标或完成答案；没有从解释文字中提取或修复动作。

这是受控测试页的一次真实任务反馈闭环。浏览器通过 adb reverse 访问 host
测试服务；不等同于外网工具、多应用复杂任务、在线自校准或投机调度闭环。
首轮推理请求到响应约42.7秒，第二轮约42.1秒，属于带资源采样的诊断，
`timing_valid_for_performance=false`，不能用作加速比结论。

每0.5秒左右采集 `/proc/uptime`、全机 CPU 计数与模型进程状态，本次导出160条
`resource-samples.csv`。可用于后续负载时间线检查；没有 GPU/HTP 利用率和能耗数据。
host 与设备时钟各自使用，不跨时钟直接相减。
