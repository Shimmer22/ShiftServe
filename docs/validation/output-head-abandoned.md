# 输出头探索停止记录

2026-11-14，用户决定停止此方向。候选词表、低维投影及安全回退的专用代码、配置、执行入口、二进制和大派生权重缓存已移除；不接入主线运行时，不继续设备试验。

实验采用Qwen3-8B Q4_0，输出头为Q6_K、4096×151936、约487MiB。三个提示为工具结果JSON、固定JSON、中文解释；排除prefill已计算的首token后，共74个独特decode位置。

- **手机CPU6候选重放**：prefill词表候选计算约0.5–0.9ms，范数检查约0.37ms；JSON条件完整头约12.8–13.5ms，包含回退后约13.6–14.8ms。候选可覆盖全部正确token，但行范数与prefill锚点增量界全部无法证明安全，真实decode回退率100%。666次重放最终argmax均与完整头一致；仅算子重放，不代表E2E。
- **本机CPU离线投影**：prefill SVD与静态权重能量坐标投影共69个条件，几何证书通过率均0。即使保留2048坐标、K4096候选召回100%，仍约97%的词无法排除。逐词上界核对无违例，参考argmax与运行时全部一致。实验性浮点余量不等于手机内核的形式化安全证明。

主要障碍是残差上界过松；高候选召回不等于能排除其余词，检查与完整回退抵消收益。以上结果仅覆盖本批方法与三条轨迹，不否定所有输出头检索方法。

参考[Accelerating LLM Inference via Vector Index Based Output Embeddings](https://arxiv.org/abs/2608.27460)：采用HNSW近似MIPS，无严格argmax保证；实验为桌面CPU FP32，Qwen3为0.6B/1.7B，不直接外推手机8B量化收益。
