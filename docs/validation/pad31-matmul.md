# 31行补齐32行并丢弃补行：最小算子验证

本次未满足“更快且数值不变”。用Qwen3.5-9B-Q4_0的layer0真实权重，固定合成F32激活，比较31行与末尾补一行零到32行、丢弃最后输出行。每种矩阵每条件10次，5次原31行先测、5次补齐先测，固定种子乱序；三种矩阵共60次正式算子测量，预热不计入。

| 权重 | 原31行总耗时 | 补32行后总耗时 | 总耗时变化 | 前31行相对L2差异 |
|---|---:|---:|---:|---:|
| QKV（K4096/N8192） | 8.117 ms | 7.951 ms | 减少2.04% | 0.3916% |
| FFN Up（K4096/N12288） | 12.563 ms | 12.186 ms | 减少3.00% | 0.3996% |
| FFN Down（K12288/N4096） | 10.827 ms | 11.844 ms | 增加9.40% | 0.3985% |

总耗时包含补零/拷贝、输入上传、计算同步、输出读回与裁剪；权重上传重排和图分配不计入。权重热驻留，输入seed20261119、均匀[-1,1]。未将旧实验的模型耗时混入本次单算子数据。

所有前31行输出均不逐位相同，均未通过 `atol=rtol=1e-5`。余弦约0.999992，最大绝对差异分别0.02329、0.00759、0.02967。与相同Q4权重解量化后的CPU F32参考相比，补齐路径相对L2误差约0.072%，原31行路径约0.39%；本次样例的补齐结果更接近该参考，但不推断完整模型任务质量。

原版v75 DSP库profile=0负责计时；私有v75布局探针profile=2独立运行验证路径。66个诊断矩阵记录全部覆盖：31行均HVX，32行均HMX。诊断耗时不进入上表，PMU槽承载路由元数据而非硬件计数。

这是算子级验证，不含H和模型状态。它验证的是独立矩阵输入行补零，未向实际prompt追加dummy token，也未截断Qwen3.5 recurrent/conv状态。完整31-token prefill的算子内padding方案仍需另验最终logits、完整状态及后续decode。数学上独立行补零保持函数不变，不保证不同数值内核的浮点输出相同。

构建入口：`scripts/build/pad31_matmul.py`；设备入口：`scripts/run/pad31_matmul.py`；分析入口：`scripts/analyze/pad31_matmul.py`。原始计时、诊断、构建和数值记录保存在 [结果目录](../../results/20261111-pad31-matmul/README.md)，完整指标见 [summary.json](../../results/20261111-pad31-matmul/summary.json)。设备通过Termux SSH持锁串行执行，完成后释放锁，不更改共享库或手机设置。
