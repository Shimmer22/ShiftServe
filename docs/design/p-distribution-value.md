# 基于 P 分布的投机准备

旧 `cost_aware` 在任何校准 P 存在 HC 收益时准备，属于存在性判定。它没有预测当前 Tool 的返回长度。

最小实现用过去 W 次已返回 P 的经验直方图 q(P)，在 Tool 发起前计算决策。本轮 P 仅在响应后写入预测器；校准时的 P 不作为到达分布。无历史、分布支持未覆盖均不准备。当前实现仅供精确 P 夹具实验，不对未覆盖整数做插值，也没有接入通用 agent 的在线调度。

设 C(P) 为 CC 完整响应计算成本，H(P) 为已 ready 的 HC 完整响应成本，A 为独立校准准备时间最大值，G 为发起前指定的 Gap 估计。返回后可按需准备的基线为 B(P)=min(C(P), A+H(P))；ready-only 提前准备成本为 E(P)=min(C(P), H(P))（G≥A），否则为 C(P)。数值不准入的 HC 不参与选择。

期望延迟收益 V=Σq(P)[B(P)−E(P)]。当 V−λA>0 时准备。λ 是提前占用准备预算的显式惩罚权重，不是测量得到的能耗换算，也不是总设备时间目标：返回后按需准备的资源成本未在该惩罚中收费。若目标改为总准备占用，必须把两侧按需准备的概率成本也计入，不能直接复用该阈值。默认机制函数 λ=1，实验配置 λ=0.5，敏感性分析覆盖 0/0.25/0.5/1。

只优化响应延迟、准备无干扰且 λ=0 时，任意正概率收益都可能触发准备。因此仅加入 P 分布并不能保证减少准备；需要明确资源目标或收益门槛。λ=1 时相对于可按需准备基线，长 Gap 的收益至多 A，因此通常不会触发。这是目标函数的性质，不应调参隐藏。

固定 G 是本轮受控实验条件，并非已完成 Gap 预测。短 Gap 会产生负收益（ready-only 提前准备无法及时完成，却失去按需选择 HC 的机会）；实际 ready 仍由原生 Router 检查。待自然 Tool 轨迹可用时，应按工具类型统计 P 与 G 的联合分布；不能把当前均匀扫描次数当作真实分布。

实验入口：`scripts/analyze/speculative_value.py` 做校准曲面敏感性分析；`scripts/profile/oracle.py --config configs/p-distribution-value-h4096-termux.json` 串行设备对照。过去 8 次窗口、36 个到达事件（12次P24、12次P32、12次交替）、每事件 always/期望价值随机相邻顺序，各条件共用独立校准，更新预测器一次。冷启动和分布切换延迟全部计入结果。单会话是机制验证，不支持自然分布泛化或跨会话稳定性结论。
